# Computer Troubleshooting Checklist

## Before Troubleshooting

* [ ] Understand the user's problem.
* [ ] Ask when the problem started.
* [ ] Check whether the problem happens repeatedly.
* [ ] Check for any error message.
* [ ] Ask whether any recent changes were made.

## Basic Checks

* [ ] Check power connection.
* [ ] Check cables and peripherals.
* [ ] Check network connection.
* [ ] Check device settings.
* [ ] Restart the computer if appropriate.
* [ ] Check available storage.
* [ ] Check for software or system updates.

## During Troubleshooting

* [ ] Identify possible causes.
* [ ] Start with simple solutions.
* [ ] Make one change at a time.
* [ ] Test the result after each major change.
* [ ] Record the actions performed.

## After Troubleshooting

* [ ] Confirm whether the problem is solved.
* [ ] Ask the user to verify the solution.
* [ ] Document the final solution.
* [ ] Record unresolved issues.
* [ ] Escalate the problem when necessary.

## Escalation Checklist

Escalate when:

* [ ] Basic troubleshooting does not solve the problem.
* [ ] Specialized technical knowledge is required.
* [ ] Hardware replacement may be required.
* [ ] The issue affects multiple users.
* [ ] Administrator access is required.
* [ ] There is a possible security concern.
